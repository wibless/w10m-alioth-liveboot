# Windows 10 Mobile LiveBoot для Poco F3

Оригинальная Windows 10 Mobile (образ HP Elite x3) на Xiaomi Poco F3 / Redmi K40 (alioth) — **из оперативной памяти**.
Ничего не прошивается и ничего не пишется в память телефона: твоё рекавери, boot и Android остаются как были,
перезагрузка возвращает телефон в Android.

Автор проекта: [t.me/SillyFemboy](https://t.me/SillyFemboy)

## Скачать

[`w10m-alioth-liveboot.zip`](w10m-alioth-liveboot.zip) — распакуй в любую папку на ПК (путь лучше без пробелов
и кириллицы), дальше — раздел «Запуск».

## Как это работает

- Телефон загружает рекавери с root-доступом по adb: либо **уже установленное** у тебя (TWRP / OrangeFox,
  через `adb reboot recovery`), либо образ TWRP, загруженный **только в RAM** (`fastboot boot`, раздел recovery
  не трогается).
- В RAM телефона копируются QEMU, диск Windows и агент экрана. Windows работает в QEMU прямо на телефоне:
  пользовательский код Windows выполняется **нативно** на ядрах Snapdragon 865, ядро Windows — в эмуляции.
- Картинка выводится на экран телефона, под ней кнопки «Назад», «Пуск», «Поиск» и кнопка экранной клавиатуры.
  Работают сенсор, кнопка питания и громкость.
- Интернет идёт по USB-кабелю с ПК (ПК раздаёт свою сеть), Windows видит его как проводную сеть.

## Что нужно

- Poco F3 / Redmi K40 (alioth) с **разблокированным загрузчиком** и включённой отладкой по USB.
- Рекавери с root по adb (TWRP или OrangeFox) — установленное, **или** образ TWRP для alioth (`-Twrp`).
- ПК с Windows 10/11: [Python 3](https://python.org) (с галочкой «Add to PATH»), [7-Zip](https://7-zip.org),
  [platform-tools](https://developer.android.com/tools/releases/platform-tools) (adb и fastboot — в PATH или в папку
  `platform-tools` рядом с этим README), ~15 ГБ свободного места.
- **Свой** FFU HP Elite x3: `MR5_Elite_x3-retail-0002.0000.0037.0001-signed_0002.0000.0037.0001.ffu`
  (Windows 10 Mobile 14393.953). Файлов Windows в пакете нет — диск собирается из твоего FFU.

## Запуск

1. **Один раз — собрать диск Windows** (40–70 минут, большая часть — первый запуск Windows на ПК):

   ```
   BuildDisk.bat -Ffu D:\путь\MR5_Elite_x3-retail-0002.0000.0037.0001-signed_0002.0000.0037.0001.ffu
   ```

   Получится `disk\w10m.qcow2` (~3 ГБ). Папку `disk\build` после этого можно удалить.

2. **Запуск на телефоне** (телефон подключён по USB, включён Android или рекавери):

   ```
   LiveBoot.bat
   LiveBoot.bat -Twrp D:\twrp-alioth.img     (если установленное рекавери без root adb)
   ```

   Копирование ~3 ГБ занимает около 2 минут, ещё 1–3 минуты — до экрана «Пуск». Пока Windows грузится,
   ничего не нажимай.

## Управление

- Внизу: «Назад», «Пуск», «Поиск»; ниже — кнопка клавиатуры (открыть/закрыть). На клавиатуре `?123` — символы.
- Короткое нажатие питания — погасить/включить экран.
- **Выход в Android — долгое нажатие питания** (или `adb reboot`).

## Ключи LiveBoot.bat

| ключ | что делает |
|---|---|
| `-Twrp <img>` | загрузить этот образ TWRP в RAM вместо установленного рекавери |
| `-Emulation` | вся Windows в эмуляции: медленнее (старт 10+ минут), запасной вариант, если быстрый режим ведёт себя странно |
| `-NoNet` | без интернета |

## Ограничения

- Около 15–20 кадров в секунду при анимациях: Windows рисует интерфейс программно (драйвера Adreno для неё нет).
- Нет Wi-Fi, звонков, камеры, Bluetooth; интернет только по USB с ПК. Часы показывают UTC.
- Экранная клавиатура — английская раскладка и символы.
- Быстрый режим изредка зависает на «Loading…» — помогает перезапуск `LiveBoot.bat`.

## Безопасность

Используются только `fastboot devices / getvar / boot` и `adb reboot recovery`. Ничего не прошивается, разделы
телефона не изменяются; всё, что делает Windows, живёт в RAM и исчезает при перезагрузке.
